Unit convention for all throughput/goodput formulas: `8 * bytes / seconds` produces **bit/s**; `8 * bytes / (10^6 * seconds)` produces **Mbit/s**. The byte boundary determines whether a result is layer throughput or application goodput; changing units does not change that distinction.

## Paper risk definitions are distinct from empirical metrics

Eqs10–13 p6 define predictive risk, not measured HFR or observed packet loss. Jfail is a horizon-wise indicator over generated trajectories; Jqos averages normalized predicted delay, jitter, loss and throughput deficit. Monte Carlo mean over10 samples is not a measured failure frequency over10 real handovers. The paper does not specify QoS clipping; negative throughput deficit when T>Ttarget is possible. Loss column percent must be converted to fraction if using lmax=.10 as fraction (P explicit convention pending clarification). RSRQ thresholds cannot be assumed calibrated for our model-derived RSRQ.

## Instrumentation boundaries for D1

S:203–275 stores mutable source/target/IMSI and a one-handover consistency condition, not a keyed attempt registry. S:740–766 installs applications and attachment checks only for UE0. `udp_packets.csv` schema has RX/TX times, sequence and bytes, no UE/flow/serving-cell key. `udp_traffic.csv` counters are one client's totals. `ue_mobility.csv` has ue_id, but no registry joining it to packet IMSI. C1's sequence contract, plotting single UE/BWP requirement and C2.1 validator's fixed UE0/IMSI2/cells1–2 must change together before multi-UE inference. Native radio callbacks loop over UE/BWP, which is useful but not proof of full multi-UE correctness.

No current export measures PRB occupancy, active/scheduled load, queues, admission rejection or NGAP signalling. Attached UE count is not PRB utilization. Future per-cell QoS must specify attribution at TX, RX, or bearer interval, especially for packets crossing handover. Always retain timestamps and attribution convention rather than averaging across changing serving cells invisibly.
