# Phase D0: proposed research extensions

Everything in this document is **P: our proposed definition/experiment**, not a paper-reproduction requirement. Priorities are planning recommendations. Feasibility distinguishes existing exported data from unverified future trace possibilities. One UE/one seed cannot establish reliability, fairness or novelty. The decision-to-execution hypothesis is already central to the reference paper; no original-contribution claim is made without a separate literature review.

| Extension / motivation | Proposed mathematical or operational definition | Data and current feasibility | Confounders | Controlled experiment | Priority / phase |
|---|---|---|---|---|---|
| Ping-pong rate: detect unstable service changes | For each completed A→B, indicator that next completed HO is B→A within preregistered W_pp. Rate=100*eligible returns/eligible A→B completions, %; right-censor anchors without W_pp follow-up; report attempt- and UE-normalized counts separately | Need per-UE ordered attempt IDs, successful cells, completion times and censor flags. Existing event types useful but single-HO logger cannot safely handle returns or several UEs | Border oscillations, speed, window choice, unequal exposure, natural route reversal, failed attempts | D2 bidirectional/repeated border path; fixed topology/traffic and paired seeds; sweep hysteresis/TTT independently after baseline | High, D2; not identifiable from current one-way single HO |
| QoS recovery: characterize service after completion | Establish pre-HO reference G0 and D0 from declared trailing reference window, excluding a guard. Recovery is earliest t after completion where K consecutive completed windows have G>=alpha*G0 and delay<=D0+beta; report time, censor at timeout, and each component separately | Existing C1 windows/delays support retrospective exploratory computation; not implemented. Need flow/UE keys, fixed windows, sufficient reference traffic and post-HO observation; G0=0 undefined | Offered load, drain near run end, time-bin alignment, lost packets censored from delay, normal fading; alpha,beta,K choices | D1/D2 extend follow-up; identical offered load/mobility, predefined windows and thresholds; no data-driven per-run favorable tuning | High, D2 analysis after identities |
| Fifth-percentile UE throughput: expose low-tail service | For each UE over common [a,b), B_u is received bytes and a,b are seconds: G_u=8*B_u/(b−a) bit/s, or G_u/10^6 Mbit/s; report empirical p05 across UEs with declared quantile method. Name UDP-goodput p05 if using application bytes; time-percentile per UE is a different metric | Per-UE keyed bytes and common active/cohort interval needed. One UE yields no meaningful across-UE tail;3/5 UEs provide unstable p05 | Inactive UEs, unequal demands, unsaturated traffic, small sample, cell placement, averaging hides outages | D3 increase UE count over repeated seeds; identical traffic profiles and paired deployment, report sample size/CI and offered load | Medium, D3 |
| Jain fairness: assess distribution across UEs | J=(sum_u G_u)^2/(n*sum_u G_u^2), dimensionless; undefined if all rates zero. Include zeros for active eligible UEs; report active population and total rate | Needs per-UE common-window goodput; not implemented. For n=1, J=1 when positive is tautological | Demand heterogeneity, scheduler, channel disparities, idle users, fairness versus low total service | D1 structural accounting; D2/3 cell-edge/interior UEs with equal offered demand, then separate saturation experiment | Medium, D2 metric / D3 scientific evaluation |
| Decision-to-execution suitability degradation: test delayed target validity | For candidate c at t_d, Q_c(t)=predeclared unitless target utility; degradation Delta_c=Q_c(t_d)−Q_c(t_exec), plus threshold-crossing fraction. Could use target RSRP only as a narrower radio metric, explicitly distinct from QoS utility | Need candidate/decision/application/verification timestamps, target measurements at both times and uncertainty/age. Current UE RRC start is not necessarily policy decision or application time; target counterfactual QoS absent. Full utility needs paired action-conditioned branches or validated replay | Selection bias, stale reports, changing interference/load, endogenous admission, execution-delay injection, counterfactual validity | First offline deterministic radio-only study with labeled report age and controlled delays; later paired branches with common exogenous mobility and justified RNG coupling. Evaluate whether degradation predicts failure/QoS independently of baseline quality | High hypothesis, D3 exploratory/D4 labels; separate literature review before novelty claim |
| Time below SINR threshold: quantify degraded radio exposure | For declared channel/BWP and gamma, estimate T_low=sum_i min(t_(i+1)−t_i,Amax)*1[S_i<gamma] over bounded valid holds; explicitly exclude unknown/stale intervals. Report seconds, T_low/T_observed, and observed-time coverage | Actual DATA/CONTROL SINR available; event-driven/nonuniform. Holding policy is an assumption, not continuously measured truth. No neighbour SINR; threshold unspecified by paper and must be proposed | DATA only when receiving, scheduling-biased sampling, control cadence, averaging support, missing spans and preattachment values | D2 compare separately by channel, sensitivity to Amax/gamma, same traffic/scheduler; validate against denser native instrumentation only in an approved later phase | Medium, D2 exploratory; no naive sample fraction as time fraction |
| Control-plane overhead per HO: expose signalling costs | Sum actual control message bytes and counts by layer/interface/attempt, divided by completed and by attempted HOs separately; report preparation/execution/path-switch phases and timing. Keep modeled bytes, retransmissions and logging overhead separate | Existing event CSV has transitions but no message byte counts; cannot infer overhead from event count. Need verified X2/RRC packet/message trace hooks; NGAP requires separate OAI/5GC environment, absent here | Header boundaries, retransmissions, context sizes, rejected candidates, bootstrap signalling, ideal-vs-real RRC, shared messages | D3 X2/RRC accounting with fixed bearer/config and paired seeds; later explicitly separate NG/OAI branch and timing scope | Medium, D3 exploratory; full NG stage beyond current simulator architecture |

Thresholds W_pp, alpha,beta,K,Amax,gamma, utility weights and observation intervals above are deliberately not assigned paper-derived values: the paper does not specify these extension contracts. Choose and preregister them before experiments, or report sensitivity analyses. Export sufficient raw observations to recompute results without rerunning simulation.

Most feasible next steps are per-UE delivery accounting and retrospective QoS recovery, then ping-pong after repeatable return mobility. Target robustness is promising but requires authentic action/timing labels and counterfactual controls; it should not precede the data contracts. PRB/load instrumentation is important for paper feature coverage but must not be approximated by attached UE count alone.
